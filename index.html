About

I've spent about five years building software at Southwest Airlines, Perficient and SBS Systems, and I like work where the backend has to be fast and the front end has to be simple.

At Southwest I worked on real-time services for ground operations: Kafka event streams, Spring Boot microservices and React front ends on AWS. Before that I built ETL pipelines and full-stack apps at Perficient, and Android and web apps at SBS Systems. Lately I've been building AI-assisted applications with LangChain and AWS Bedrock.

I care about code that's easy to maintain, systems that hold up in production, and using tools like GitHub Copilot and Amazon Q to move faster without cutting corners. I have a B.S. in Business Information Systems and an M.S. in Information Systems from UT Arlington.

Outside of work I compose and play music on the keyboard and build sci-fi worlds inspired by the novels and comics I read.
